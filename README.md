# QRStamp

**In-browser QR code generator.** Type text or a URL, tweak size and error correction, and download PNG or SVG. Live preview updates as you type.

**Live:** https://shaikbasha1437.github.io/qrstamp/

## Privacy

All generation runs **only in your browser**. Your text never leaves this tab — no uploads, no accounts, no analytics.

## Features

- Live QR preview from text or URL
- Size control (128–512px)
- Error-correction levels L / M / Q / H
- Quiet-zone (margin) control
- Download PNG
- Download SVG
- Copy image to clipboard (when supported)
- Sample / clear
- Works offline after first visit (PWA)
- Vendored client-side QR library (no backend)

## How to use

1. Open the live page (or open `index.html` locally).
2. Paste a URL or any text.
3. Adjust size, error correction, and quiet zone.
4. Download PNG or SVG.
